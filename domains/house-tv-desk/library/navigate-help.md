# House TV — simple navigation

- **Kodi:** open the Kodi app from the home screen (or use House Remote → Kodi).
- **Movies:** Kodi → Videos → Files → **House Movies**.
- **HDMI:** TV input must match the cable (see house docs HDMI-EASY).
- **Remote:** D-pad on House Remote page, or physical remote when paired.
- **Desk:** this chat only *suggests*; it does not change settings or approve work.
