# Minimal CLI domain

**Root = this directory** (or any folder with `CURRENT.md`).

```bash
cd domains/minimal-cli   # or your project root
export OPENROUTER_API_KEY=...   # or GROQ_API_KEY — docs/FREE-API.md
aether desk
```

| Key | Action |
|-----|--------|
| `c` | show CURRENT |
| `e` | edit CURRENT |
| `n` / `p` | Next + preflight |
| `g` | free model propose |
| `w` | save proposal to `.aether/` |
| `q` | quit |

No approve hotkey — edit the file instead.
