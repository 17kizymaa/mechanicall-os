A member built an "agent" inside his client folder, gave it a name, and asked if he was doing it wrong. He wasn't. He'd found the whole trick.

A sub-agent is one model copying itself and reading instructions. Your folder structure already is those instructions, which is why routing sub-agents through folders cuts instruction tokens by around 97 percent. The word agent is a label we put on automation so we can comprehend it at a scale we've never had before. It's UI and UX design.
