# 01 Script Identity
A single POSIX shell script: AETHER_VERSION 0.2, file name aether, reads CURRENT.md as source of truth. It does not create it.

# 02 drift
Reports whether git is dirty or clean. Does not decide commits; that remains human authority.

# 03 approve
Records the human Yes on CURRENT.md. Does not run Next automatically; Next is a separate gate.

# 04 apply
Copies a fenced proposal onto CURRENT.md. It is not a Yes action; it materializes what was approved.

# 05 Garden State
spark graph session seed are installed and form the later prune list. They persist outside com.mechanicall.pocket.demo 0.19.21-loop-from-20 versionCode 46.

# 06 Gate Bucket
The CLI owns the gate bucket: capture is not the job. It records what was approved, not whether it passed.
