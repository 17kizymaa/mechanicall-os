The best APK MVP is **one native rack that sits one folder through Bind → Plan → Draft → Decide+Why → Receipt**, with CRT as a dark terminal of that plan, Send as an overlay that is not Yes, and FILES as the phone’s own manager.

## The sitting (narrated)

A person opens Mechanicall. Splash. Then the rack.

**Bind.** The CRT says `BIND IDLE` / `Name a folder. One project.` The steel pad is the only work. PLAN / DRAFT / DECIDE / RECEIPT keys are there as furniture; they do not become the product until a folder is named. They pick a directory on the phone. The app asks for all-files access because the protocol lives as files, not as a hidden cloud. If they point at this operator tree, the pocket **refuses**. The glass says so. That refusal *is* the product.

**Plan.** After bind they land on PLAN. LCD: `PLAN IDLE` / `Next: …` / `Tap a key. Glass holds law.` Five keys: OBJECTIVE, NEXT, KEEP, REJECT, LIMITS. Those keys are not a protocol museum. They are the published CURRENT, as plates. Tap STATUS CRT: the millwork goes away. A maximised **dark terminal** pages the law. Dismiss: back to the chassis. The plan is readable without a CLI.

**Draft.** Bank DRAFT opens an **isolated workshop**. Live field vs proposed field. Fluency (the desk, a model, a typed edit) proposes. Save writes `PROPOSE-CURRENT.md` in the bound folder. CURRENT bytes do not move. The footer can say it out loud: *not CURRENT*.

**Send (optional, honest).** The middle lamp is not Decide. It opens an overlay of the Send **module**: idle / staging / offer. Dismiss returns to the rack. It does not write CURRENT. It is not FILES.

**FILES.** A different hit. The phone’s file manager opens the bound folder. The person can `cat` what the glass is talking about. That is filesystem-as-truth without teaching POSIX.

**Decide.** One plaque. Why on the glass first — empty Why will not stamp. First tap arms (`Publish? tap plaque again`). Second tap is Yes: apply the propose, native approve, write a receipt, land on RECEIPT. Bind / Send / JOIN / WAKE / LOAD / STREAM / FILES / opening the app are **not** this tap.

**Receipt.** Tomorrow they open RECEIPT. It shows what they already said. If nothing was stamped, it is **empty**. Empty is honest. Fake agree is a different product.

**GATE SEQ.** The purple row is an instrument (IDLE / WARM / LOAD / STREAM / QUIET), not typing dots, not a renamed Send. It can be quiet. Quiet is allowed.

That is the whole MVP. Six beats. One View. One folder.
