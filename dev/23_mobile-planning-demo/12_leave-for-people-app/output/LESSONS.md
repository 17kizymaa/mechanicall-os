## Keep in the people-app

1. **Their folder, their identity.** Bind a path that is not `mechanicall-os`. Never ask them to become the operator (`17kizymaa@gmail.com` is not an invite).
2. **GET is never Yes.** Opening a page, cloning a workspace, reading PLAN.md — none of these apply CURRENT.
3. **Silence is never Yes.** Closing the tab, waiting, “looks good” in chat — none apply.
4. **Agent writes PROPOSE only.** Yes is the human. Receipt lands in *their* folder.
5. **One screen is enough:** plan, draft, Yes, Not yet, receipt. No verb museum. No bubble chat as the face.
6. **They must be able to say “I didn’t say yes” tomorrow** — `RECEIPT.md` they can open without this git tree.
7. **Refuse operator tree.** Same `refuse_if_operator` idea as the pocket engine.

## Reject in the people-app (learned the hard way)

1. **Tailscale-as-me is not a send path.** A stranger with the Tailscale app still cannot open a table that only exists on the operator tailnet. Do not make “join my tailnet as me” the front door.
2. **Funnel / public bind** of the face or Ollama. Correctly refused. Stay refused.
3. **POST Yes for them.** The CLI must not tap.
4. **Chrome without law.** An APK (or any UI) with no `aether` on the bound folder is decoration.
5. **Dual Next.** Do not run the sitting and the people-app as two live Nexts.
6. **Play Store this Next.** Still a factory + copyable workspace, not a store listing.
