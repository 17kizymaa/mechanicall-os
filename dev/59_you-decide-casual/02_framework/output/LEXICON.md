# LEXICON — house vs workshop

**Not Yes.** Face words for `you-decide-casual`. Pair with `CASUAL-UI.md`.

Mum is not taught a plugin. A son does not come home and ask his mother to learn a VST.

## Prefer (house)

| Word | Means |
|------|--------|
| house | the bound folder + its plan |
| door | Bind: name the folder |
| table | where papers sit (plan / draft) |
| papers | files she can `cat` tomorrow |
| plan | live `CURRENT.md` |
| draft | `PROPOSE-CURRENT.md` on the table, not the plan |
| stamp | Decide. The only Yes. |
| why | her reason, required with the stamp |
| not yet | leave Decide; Next kept |
| receipt | what happened; empty is empty |
| bag | Send + FILES: pack / open the folder |
| waiting | GATE as ETA, not a door |
| open | OEM files / a paper room. Chore. |

## Do not put on the face (workshop)

| Word | Why it fails M9 |
|------|-----------------|
| chassis / millwork / rack | VST literacy |
| CRT / LCD / phosphor / tube | terminal as the room |
| plugin / VST / DAW | workshop |
| banks / wells / lamps | instrument chrome |
| IsolatedMode / dest | debug geography |
| LawPages / `LAW ` dump | operator |
| Confirm | forbidden control; he does not tap her Yes |
| Publish (as chat verb) | use stamp |
| GATE (as a door into papers) | waiting is a chore |

| please confirm / don’t forget | nag |

## Keep (product, not chrome)

- **Mechanicall**
- **You Decide**
- folder name after bind
- Next id as the name of the one thing (a file field, not a Play title)

## Copy tests

A string on the face **fails** if it:

1. Teaches a workshop (`CRT`, `chassis`, `plugin`, `GATE` as a room name).
2. Talks down (`easy`, `simple mode`, `don’t worry`, `for non-technical`).
3. Nags toward Yes (`confirm`, `please approve`, streaks).
4. Claims a stamp he did not get (`published`, `applied`, `done` on CURRENT without Decide).

A string **passes** if a person who never saw a DAW still knows: this is the plan, this is a draft, this is the stamp, this is what happened.
